# 捞职 JobLasso · dsh-job-lasso

[English](README.md)

写这个插件，纯粹是因为我自己在找工作。

每天早上打开 BOSS、猎聘、LinkedIn，关键词搜一遍，城市切一遍，远程筛选点一遍，翻两页，投几份，然后等一个已读不回。第二天再来一遍。找远程岗位尤其折磨：岗位散在不同站点，很多还藏在「远程」两个字里，靠人肉刷根本刷不完。

所以我写了「捞职」：每天定时把几个站的远程岗位捞一遍，按我自己的画像（岗位、技能、薪资、经验）打分，只把值得看的放进 Harness 侧边栏。它不替我投简历，也不替我聊天，只是把「重复找」这件事自动化，让我能把时间花在改简历和准备面试上。

## 它做什么

- 每天定时抓 BOSS直聘、猎聘、拉勾（实验性）、电鸭社区、LinkedIn 领英、V2EX 酷工作。
- 远程优先：搜索词自动带「远程」，非远程岗位直接过滤。
- 按画像打分：岗位名、技能、薪资、经验、学历、排除词、公司黑名单。
- 面板里按「今日 / 强匹配 / 值得看 / 收藏 / 已忽略」查看，可导出 CSV。
- 数据只存在本机，不上传，也不带任何账号凭据。

## 安装

```sh
dsh plugin add github:jxhsjxhs/dsh-job-lasso
```

指定 profile：

```sh
dsh plugin --profile web add github:jxhsjxhs/dsh-job-lasso
```

装完重载 Harness，侧边栏会出现「捞职」。

## 环境要求

- 带 Web UI 的 DeepSeek Harness。
- 本机装有 Google Chrome（Chromium / Edge 也行）。插件用的是自己独立的 Chrome 配置，不碰你日常浏览器。
- 想看 BOSS 的结果需要 BOSS直聘账号；猎聘、电鸭、LinkedIn、V2EX 免登录。

## 第一次用

1. 打开 **捞职 → 设置**，填岗位关键词、期望薪资、技能，勾选要用的站点。
2. BOSS（和可选的拉勾）需要点 **登录 BOSS / 登录拉勾**，在弹出的 Chrome 窗口里扫码，回来点 **完成登录**。
3. 点 **立即捞一次**。第一次通常 30–90 秒，因为每个关键词都要开一次无头浏览器。

## 支持的来源

| 来源 | 方式 | 登录 | 说明 |
| --- | --- | --- | --- |
| BOSS直聘 | 无头 Chrome + 搜索接口 | 需要 | 有频率限制，连续请求会 `code 37` 并进入冷却 |
| 猎聘 | 无头 Chrome | 免登录 | 远程岗位的主要来源 |
| 拉勾 | 无头 Chrome | 需要 + 滑块 | 实验性：阿里云 WAF 经常拦无头浏览器 |
| 电鸭社区 | 公开 API | 免登录 | 中文远程 / 兼职岗位 |
| LinkedIn 领英 | 访客搜索接口 + Chrome | 免登录 | `location=China`、远程筛选、只保留中文岗位 |
| V2EX 酷工作 | 公开 API | 免登录 | 最新 10 条帖子 |

## 打分规则

| 因素 | 影响 |
| --- | --- |
| 明确远程 | +18 |
| 疑似远程 | +6 |
| 非远程（远程模式） | 不收录 |
| 岗位名命中关键词 | +16，多命中再加 |
| 技能命中 | 每项 +4，最多 +12 |
| 薪资覆盖期望 | +10；低于期望 −10 到 −16 |
| 经验对得上 | +4；门槛过高 −10 |
| 学历要求高于画像 | −12 |
| 排除词 / 公司黑名单 | 不收录 |

默认强匹配 ≥ 82，值得看 ≥ 66。改画像会对已存岗位重新打分。

## 数据与隐私

- 岗位、画像和日志存在 `~/.dsh-job-lasso/store.json`。
- 浏览器登录态存在 `~/.dsh-job-lasso/chrome-profile-*`，只在本机，不进仓库。
- 插件不向任何第三方发送数据，只打开你启用的招聘站。
- 仓库里没有任何 cookie、token 或个人信息；`store.json`、`chrome-profile*`、`.env` 都在 `.gitignore` 里。

## 已知限制

- 远程岗位本来就少，一天 5–20 条是常态。
- BOSS 对连续请求敏感：每次最多两个查询、间隔 25–35 秒，触发 `code 37` 后自动冷却。
- 拉勾有阿里云 WAF，无头浏览器基本会被拦。
- LinkedIn 和部分来源没有薪资字段，列表里会显示「薪资未知」。
- 只读搜索结果页，不抓职位详情，JD 不参与打分。
- 定时是进程内的，Harness 关掉就不会跑。

## 一点自知之明

它不是「保 offer」神器，只是替你把每天那半小时的重复劳动省下来。如果它也能帮到同样在找远程工作的你，那就够了。
